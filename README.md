# SmartCart 🛒

SmartCart is a data-driven Android application designed to help consumers navigate the rising cost of living by dynamically comparing prices across major Canadian retailers like Walmart, Costco, and Real Canadian Superstore. 

### 👩‍💻 My Contributions (Frontend Lead)
As the Frontend Lead for this group project, I was responsible for the complete user interface and application flow. My specific development work includes:

* **Complete App UI/UX:** Designed and built all visual screens using Material Design, creating a professional and friendly user experience.
* **Complete App Navigation:** Engineered the global navigation architecture using a custom `BaseFragment` to smoothly handle the bottom menu and back-button routing.
* **User Profile Page:** Created the dynamic account screen using `SessionManager` and interactive pop-ups so users can securely view, edit, and log out of their accounts.

### 📱 Core App Features
* **Price Comparison Engine:** Instantly compares grocery items across three supermarkets with a visual "Lowest Price" badge.
* **Cloud-Based List Management:** Allows users to securely create, save, and modify shopping lists.
* **Built-in Store Catalog:** A searchable library of budget-friendly items.

### 🛠️ Tech Stack (Frontend)
* Kotlin
* Android Studio / XML
* Material Design Components
* SharedPreferences & Session Management
